🌿 AgriGuard AI Dashboard

About the Project

The AI-Based Wildlife Monitoring and Farmer Safety System is a full-stack prototype designed to bridge technology and agriculture. It utilizes computer vision (YOLOv8) to assist farmers in monitoring fields for wildlife intrusion and dispatches real-time SMS alerts directly to mobile phones.

Technology Stack

  • Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
  • Backend: Python, Flask
  • AI Model: Ultralytics YOLOv8 (Pretrained COCO)
  • Image Processing: OpenCV
  • Database: SQLite
  • Mobile Notification Gateway: Twilio REST API

Limitations & Future Scope

The current prototype uses a pretrained YOLO model trained on COCO classes (elephants, bears, birds, etc.). Specific regional wildlife such as wild boars or certain deer species require custom dataset fine-tuning. Future enhancements will integrate live CCTV video streams, edge devices like Raspberry Pi, and sound deterrence speakers.
